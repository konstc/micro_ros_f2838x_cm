Third-party components
=====================

This repository contains original code, small patches applied at build time to
the components below, and the few third-party files named in the notes below.
The components themselves are fetched from their upstream sources (micro-ROS,
ROS 2) or referenced from the user's C2000Ware and Code Composer Studio
installations (TI); they are not redistributed here.

micro-ROS and ROS 2 packages (linked into libmicroros.a)
  Source:  https://github.com/micro-ROS, https://github.com/ros2, https://github.com/eProsima
  License: Apache-2.0 (individual packages may carry BSD-3-Clause; see each
           repository and build_info.json for the exact set and revisions)

C2000Ware (driverlib_cm, device support, lwIP port, Ethernet driver glue)
  Source:  https://www.ti.com/tool/C2000WARE
  License: BSD-3-Clause (Texas Instruments)
  Note:    CM projects link C2000Ware's prebuilt driverlib_cm.lib from the
           local installation; device/f2838x/cm/include/driverlib_cm_tiarmclang.h
           only wraps its headers.

  Note:    device/f2838x/cm/startup/startup_cm.c is derived from C2000Ware's
           startup_cm_freertos.c (MIT license, Texas Instruments).

  Note:    boards/tmdscncd28388d/targetConfigs/TMDSCNCD28388D_attach.ccxml
           is based on C2000Ware's device_support/f2838x/common/targetConfigs/
           TMS320F28388D.ccxml.

Code Composer Studio GEL scripts (modified copies)
  Source:  Code Composer Studio 21.0.1, ccs_base/emulation/gel/f28388d_cpu1.gel
           and f28388x_cm.gel (Version 2.00.0)
  License: TI TSPA limited license, reproduced at the end of this file; for use
           with TI devices only
  Note:    boards/tmdscncd28388d/targetConfigs/f28388d_cpu1_attach.gel and
           f28388x_cm_attach.gel; the changes are listed at the top of each.

FreeRTOS Kernel (kernel sources referenced from C2000Ware)
  Source:  https://github.com/FreeRTOS/FreeRTOS-Kernel
  License: MIT
  Note:    device/f2838x/cm/freertos_port/ contains the unmodified upstream
           portable/GCC/ARM_CM3 files at tag V11.3.0, with their MIT headers.

lwIP 2.1.2 (shipped with C2000Ware)
  Source:  https://savannah.nongnu.org/projects/lwip/
  License: BSD-3-Clause
